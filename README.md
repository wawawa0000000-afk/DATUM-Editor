# DATUM-Editor（MiniEditor）

Java（Swing）で作ったテキストエディタです。外部ライブラリは使っていません。
横書き・縦書き・KJ法ボードの3種類の文書を、タブと画面分割で並べて扱えます。

## ビルド方法

JDK 17 以上と Maven が必要です。

```
mvn package
```

成功すると `target/minieditor.jar` ができます。

## 実行方法

```
java -jar target/minieditor.jar
```

### Windows で動かす

Java で書いてあるので、同じ `minieditor.jar` が Windows・macOS・Linux のどれでも動きます。

1. JDK 17 以上を入れる（例：https://adoptium.net/ ）
2. `minieditor.jar` と `DATUM-Editor.bat` を同じフォルダに置く
3. `DATUM-Editor.bat` をダブルクリックする（または `java -jar minieditor.jar`）

`.jar` は、どの OS で作っても同じものが使えます。Windows 側で `mvn package` をやり直す必要はありません。

### Linux のデスクトップから起動する

`~/Desktop/DATUM-Editor.desktop` のようなランチャーを置き、`Exec=` に `java -jar <minieditor.jar の場所>` を書きます。

## 機能一覧

### 文書の種類

| 種類 | 内容 | 保存形式 |
|---|---|---|
| テキスト | 横書き。行番号、カーソル行の強調、折り返し | `.txt` / `.json` |
| 縦書き | 右上から下へ書き、左へ進む。句読点・かっこ・長音・半角文字は縦書き用に配置 | `.txt` / `.json` |
| KJ法ボード | カード（付箋）、グループ枠、カード同士をつなぐ線 | `.json` |

- 「書式 → 横書き ⇔ 縦書き を切り替え」で、同じ文章を横書き・縦書きのどちらでも表示できます。

### ファイル
- 新規（テキスト / 縦書き / KJ法ボード）、開く、保存、名前を付けて保存、タブを閉じる、終了
- 読み書きは UTF-8 です。
- `.txt` は本文だけを保存します。`.json` は、種類・フォント・折り返し・カードの位置なども保存します。
- 開くときは、JSON の中身を見て種類を自動で判定します。このアプリの形式ではない `.json` は、中身をそのままテキストとして開きます（保存しても形式は変わりません）。
- 未保存の変更があるタブを閉じる・終了するときは、確認ダイアログを出します。
- **PDF として書き出す**（Ctrl+Shift+P）：テキストと縦書きは A4 の紙に割り付け（白地に黒文字、ページ番号付き）、KJ法ボードは全体を1ページにします。
- 未保存のタブには `●` が付きます。読み書きに失敗したときは、ダイアログで知らせます。

### タブと画面分割
- 複数の文書をタブで開けます（`+` で追加、`×` または中ボタンで閉じる）。
- 「表示 → 画面を分割」で左右（または上下）に2つ並べ、それぞれ別の文書・別の種類を表示できます。
- タブを反対側へ移動できます。

### 編集
- 元に戻す / やり直し、切り取り / コピー / 貼り付け、すべて選択

### 検索・置換（テキスト・縦書き）
- 入力するたびに、一致箇所をすべて水色で表示します（今いる場所は明るい水色）。
- Enter で次へ、Shift+Enter で前へ。最後まで行くと先頭に戻ります。件数と、何件目かを表示します。
- `Aa` ボタンで、大文字と小文字を区別するかを切り替えます。
- 置換した場所は緑で表示します。「すべて置換」は、「元に戻す」1回で戻せます。

### KJ法ボードの操作

Miro・FigJam・Mural などのオンラインのボードにある機能を参考にしています。

| 操作 | 内容 |
|---|---|
| 何もない所をダブルクリック | カードを追加 |
| カードをダブルクリック / Enter | 文字を編集（Ctrl+Enter か外をクリックで確定、Esc で取り消し） |
| ドラッグ | 移動（グループ枠を動かすと、中のカードも一緒に動く） |
| 何もない所からドラッグ | 囲んだカードをまとめて選択（Shift+クリックで追加・解除） |
| ふちや角をドラッグ | 大きさを変える（ふちに触れると矢印の形が変わる。カードもグループ枠も同じ） |
| Ctrl+ホイール / 中ボタンでドラッグ | 拡大・縮小 / 表示位置を動かす |
| 右クリック | 色、投票、矢印、整列、グループ化、複製、削除 |
| Delete | 選んでいるカードを削除 |

- **一括追加**：複数行の文章を貼り付ける（Ctrl+V）か「ボード → カードを一括追加」で、1行につき1枚のカードになります。
- **グループ化**：カードを選んで Ctrl+G を押すと、それらを囲むグループ枠ができ、名前を付けられます。
- **整列**：カードを格子状に並べ直します。「色ごとに並べる」は、同じ色を縦の列にまとめます。
- **ドット投票**：カードに票（赤い点）を付けて、重要なものを見分けられます。
- **矢印**：右クリック →「矢印でつなぐ」で、カードの関係を表せます。
- **画像として書き出す**：ボード全体を PNG 画像にします。
- カードの文字が入りきらないときは、カードが自動で縦に伸びます。

### 書式・表示
- フォントの種類とサイズの変更、文字の拡大・縮小、折り返し、行の縞模様の切り替え
- VS Code に近い暗い配色、ステータスバー（行・列・文字数・文字コード・保存形式）

| 文字を大きく / 小さく | Ctrl+;（Ctrl+Shift+; や Ctrl+= でも可） / Ctrl+- |
| 横書き ⇔ 縦書き | Ctrl+Shift+T |

縦書きでは、↓ が次の文字、↑ が前の文字、← が次の行、→ が前の行です。

## 構成

```
src/main/java/com/example/minieditor/
├── Main.java               起動するクラス
├── EditorFrame.java        ウィンドウ。メニュー・開く・保存・閉じる・分割
├── EditorGroup.java        タブの帯と、その下の文書1枚
├── EditorPane.java         文書の共通部分（保存先・未保存の状態）
├── TextEditorPane.java     横書きの文書
├── VerticalTextPane.java   縦書きの文書（文字を自分で描く）
├── KjPane.java             KJ法ボード
├── Searchable.java         検索・置換ができる文書の約束（interface）
├── FindBar.java            検索・置換のバー
├── StripedTextArea.java    縞模様とカーソル行を描くテキストエリア
├── LineNumberGutter.java   行番号
├── Json.java               JSON の読み書き（手書き）
├── PdfWriter.java          PDF の書き出し（手書き）
├── PagePrinter.java        文章を A4 のページに割り付ける
├── FileService.java        ファイルの読み書き（UTF-8）
├── Theme.java              色とフォント
└── FlatScrollBarUI.java    細いスクロールバー

src/main/resources/icon.png  アイコン
DATUM-Editor.bat             Windows 用の起動ファイル
```

## JSON の形式

```json
{
  "format": "datum-editor",
  "version": 1,
  "mode": "text",
  "fontName": "Monospaced",
  "fontSize": 48,
  "wrap": false,
  "text": "本文"
}
```

`mode` は `text`（横書き）・`vertical`（縦書き）・`kj`（KJ法）のいずれかです。
KJ法では `text` の代わりに、`cards`（位置・大きさ・色・票数・文字）と `links`（矢印）を保存します。

## 制限

- タイトルバー（ウィンドウ最上部）の色は OS が描くため、アプリからは変えられません。
- 縦書きには、ルビ・縦中横・禁則処理はありません。
- 検索・置換は、KJ法ボードでは使えません。
- 複数人での同時編集や、クラウドへの保存はありません（ファイルは手元に保存します）。
- PDF は、1ページを1枚の画像として入れています（日本語フォントを PDF に埋め込む処理を避けるため）。見た目はどの PC でも同じですが、PDF の中の文字を選択・検索することはできません。
- Linux と Windows で動作を確認しています。macOS では、まだ実際に動かして確かめていません。

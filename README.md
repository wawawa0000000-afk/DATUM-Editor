# DATUM-Editor（MiniEditor）

Java（Swing）で作った、シンプルなテキストエディタです。外部ライブラリは使っていません。

## ビルド方法

JDK 17 以上と Maven が必要です。

```
mvn package
```

成功すると `target/minieditor.jar` ができます。

## 実行方法

```
java -jar target/minieditor.jar
```

## 機能一覧

### ファイル
- 新規（Ctrl+N）：未保存の変更があれば確認してから、文書を空にします。
- 開く（Ctrl+O）：ファイルを選んで読み込みます（UTF-8）。
- 保存（Ctrl+S）：保存先が決まっていればそのまま上書き、決まっていなければ「名前を付けて保存」を開きます。
- 名前を付けて保存：保存先と形式（テキスト `.txt` / JSON `.json`）を選べます。拡張子は自動で補います。同じ名前のファイルがあれば、上書きするか確認します。
- 終了：未保存の変更があれば確認してから終了します。×ボタンでも同じ確認が入ります。
- タイトルバーに、ファイル名と未保存マーク（`*`）を表示します。

### 編集
- 元に戻す（Ctrl+Z）／やり直し（Ctrl+Y）
- 切り取り（Ctrl+X）／コピー（Ctrl+C）／貼り付け（Ctrl+V）
- すべて選択（Ctrl+A）

### 検索・置換
- 検索（Ctrl+F）：画面上部にバーを表示します。Enter で次へ、Shift+Enter で前へ移動し、最後まで行くと先頭に戻ります（ループ）。一致した件数と、何件目かを表示します。見つからないときは、バーの中に「見つかりません」と表示します。Esc で閉じます。
- 置換（Ctrl+H）：検索バーの下に置換欄が出ます。「置換」は今ハイライトしている場所だけを置き換え、「すべて置換」は一致するものをすべて置き換えます。

### 書式
- フォント変更：フォントの種類とサイズを選べます。
- 折り返し：行の折り返しの有無を切り替えられます。

### 画面
- 1行おきに背景の色を変える、縞模様の表示（`StripedTextArea`）。
- 背景が黒のダークテーマ（メニュー・検索バー・ステータスバーを含む）。
- ステータスバーに、カーソルの行番号・列番号・文字数を表示します。

## 構成

```
src/main/java/com/example/minieditor/
├── Main.java              起動するクラス
├── EditorFrame.java       画面・メニュー・検索置換・保存の処理
├── FileService.java       ファイルの読み書き（UTF-8）
└── StripedTextArea.java   1行おきに背景色を変えるテキストエリア
```

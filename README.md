# DATUM-Editor（MiniEditor）

Java（Swing）で作ったテキストエディタです。外部ライブラリは使っていません。
横書き・縦書き・カードボードの3種類の文書を、タブと画面分割で並べて扱えます。

## ビルド方法

JDK 17 以上と Maven が必要です。

```
mvn package
```

成功すると `target/minieditor.jar` ができます。

## 実行方法

```
java -jar target/minieditor.jar
```

### Windows で動かす

Java で書いてあるので、同じ `minieditor.jar` が Windows・macOS・Linux のどれでも動きます。

1. JDK 17 以上を入れる（例：https://adoptium.net/ ）
2. `minieditor.jar` と `DATUM-Editor.bat` を同じフォルダに置く
3. `DATUM-Editor.bat` をダブルクリックする（または `java -jar minieditor.jar`）

`.jar` は、どの OS で作っても同じものが使えます。Windows 側で `mvn package` をやり直す必要はありません。

### Linux のデスクトップから起動する

`~/Desktop/DATUM-Editor.desktop` のようなランチャーを置き、`Exec=` に `java -jar <minieditor.jar の場所>` を書きます。

## 機能一覧

### 文書の種類

| 種類 | 内容 | 保存形式 |
|---|---|---|
| テキスト | 横書き。行番号、カーソル行の強調、折り返し | `.txt` / `.json` |
| 縦書き | 原稿用紙（20字×20行）に書く。ルビ・傍点・ぶら下げ・縦中横に対応 | `.txt`（なろう形式） / `.json` |
| カードボード | カード（付箋）、グループ枠、カード同士をつなぐ線 | `.json` |

- 「書式 → 横書き ⇔ 縦書き を切り替え」で、同じ文章を横書き・縦書きのどちらでも表示できます。

### 縦書き：原稿用紙とルビ（「小説家になろう」形式）

縦書きの文書は、**原稿用紙（20字×20行、400字詰め）** の形で表示されます。

- 1行は 20 マスで、20 行ごとに1枚の紙として区切り、右から左へ並べます（中央は少し空けてあります）。
- マスの大きさは、20 マスがちょうど収まるように、ウィンドウの高さに合わせて決まります。
- 各行の右にある細い欄が **ルビ欄** です。ルビ欄をクリックすると、となりの文字にふりがなを書き込めます。
- ステータスバーに「原稿用紙 2 / 5 枚」のように、今いる枚数と全体の枚数が出ます。
- 「書式 → 原稿用紙（20字×20行）」（Ctrl+Shift+G）で、マス目のないふつうの縦書きに切り替えられます。
- PDF に書き出すと、A4 横向きの原稿用紙（1ページが1枚）になります。

ルビ（ふりがな）は親文字の右に小さく表示されます。記号は画面に出ません。
`.txt` で保存するときに「小説家になろう」の記法に直して書き出すので、保存したファイルはそのまま投稿欄に貼り付けられます。開くときは、記法を読み取ってルビに戻します。

ルビの振り方は3通りあります。

- **ルビ欄をクリック**：文字の右のルビ欄をクリックすると、その文字（文字を選んでいれば、選んだ範囲）のふりがなを入力できます。
- **メニューから**：文字を選んで「書式 → ルビ（ふりがな）を振る」（Ctrl+R）。文字のすぐ横に入力欄が出るので、ふりがなを打って Enter。空にして Enter で外れ、Esc で取り消しです。ルビの付いた文字をダブルクリックするか、その上で Ctrl+R を押すと、書き直せます。
- **打ち込みで**：`｜山田《やまだ》` のように記法をそのまま打つと、`》` を打った時点でルビに変わります。

| 打ち込む形（＝保存される形） | 意味 |
|---|---|
| `｜山田太郎《やまだたろう》` | `｜` から `《` までの文字に、ルビを振る |
| `漢字《かんじ》` | 漢字が続いているときは、`｜` を省略できる |
| `漢字(かんじ)` `漢字（かんじ）` | かっこでもよい（中が、ひらがな・カタカナだけのとき） |
| `｜《そのまま》` | `｜` の直後がかっこなら、ルビにしない |
| `｜重《・》｜要《・》` | 傍点（1文字ずつ「・」を振る） |

親文字もルビも 10 文字までです（「小説家になろう」の決まり）。保存するときは、すべて `｜親文字《ルビ》` の形にそろえます。

- **傍点**：文字を選んで「書式 → 傍点を付ける」（Ctrl+Shift+R）。
- **外す**：「書式 → ルビ・傍点を外す」。
- ルビは文字に付いているので、前に文章を足しても同じ文字に付いたままです。親文字を消すと、ルビも消えます。
- コピーすると記法の形でクリップボードに入り、貼り付けるとルビに戻ります。
- 横書きの画面は文字だけを扱うので、記法をそのまま表示します。「横書き ⇔ 縦書き」で切り替えると、相互に変換されます。

縦書きでは、ほかに次の組み方をしています。

- **ぶら下げ**：行の先頭に「、」「。」や閉じかっこが来るときは、前の行の一番下に置きます。
- **縦中横**：半角の数字2桁（`12`）や `!?` は、横に並べたまま1文字ぶんに収めます。1桁の数字は立てて表示します。

### ファイル
- 新規（テキスト / 縦書き / カードボード）、開く、保存、名前を付けて保存、タブを閉じる、終了
- 読み書きは UTF-8 です。
- `.txt` は本文だけを保存します。`.json` は、種類・フォント・折り返し・カードの位置なども保存します。
- `.txt` は「縦書きで開く」（Ctrl+Shift+O）を使うと、縦書き（原稿用紙）で開きます。縦書きの文書を見ているときは、ふつうの「開く」でも縦書きで開きます。
- すでに開いているファイルを選んだときは、もう1つ開かずに、そのタブを表示します（同じファイルを2か所で編集して、上書きし合うのを防ぐため）。「縦書きで開く」で選んだ場合は、そのタブをその場で縦書きに切り替えます。未保存の変更は、そのまま残ります。
- 開くときは、JSON の中身を見て種類を自動で判定します。このアプリの形式ではない `.json` は、中身をそのままテキストとして開きます（保存しても形式は変わりません）。
- 未保存の変更があるタブを閉じる・終了するときは、確認ダイアログを出します。
- **PDF として書き出す**（Ctrl+Shift+P）：テキストと縦書きは A4 の紙に割り付け（白地に黒文字、ページ番号付き）、カードボードは全体を1ページにします。
- 未保存のタブには `●` が付きます。読み書きに失敗したときは、ダイアログで知らせます。

### タブと画面分割
- 複数の文書をタブで開けます（`+` で追加、`×` または中ボタンで閉じる）。
- 「表示 → 画面を分割」で左右（または上下）に2つ並べ、それぞれ別の文書・別の種類を表示できます。
- タブを反対側へ移動できます。

### 編集
- 元に戻す / やり直し、切り取り / コピー / 貼り付け、すべて選択

### 検索・置換（テキスト・縦書き）
- 入力するたびに、一致箇所をすべて水色で表示します（今いる場所は明るい水色）。
- Enter で次へ、Shift+Enter で前へ。最後まで行くと先頭に戻ります。件数と、何件目かを表示します。
- `Aa` ボタンで、大文字と小文字を区別するかを切り替えます。
- 置換した場所は緑で表示します。「すべて置換」は、「元に戻す」1回で戻せます。

### カードボードの操作

Miro・FigJam・Mural などのオンラインのボードにある機能を参考にしています。

| 操作 | 内容 |
|---|---|
| 何もない所をダブルクリック | カードを追加 |
| カードをダブルクリック / Enter | 文字を編集（Ctrl+Enter か外をクリックで確定、Esc で取り消し） |
| ドラッグ | 移動（グループ枠を動かすと、中のカードも一緒に動く） |
| 何もない所からドラッグ | 囲んだカードをまとめて選択（Shift+クリックで追加・解除） |
| ふちや角をドラッグ | 大きさを変える（ふちに触れると矢印の形が変わる。カードもグループ枠も同じ） |
| Ctrl+ホイール / 中ボタンでドラッグ | 拡大・縮小 / 表示位置を動かす |
| 右クリック | 色、投票、矢印、整列、グループ化、複製、削除 |
| Delete | 選んでいるカードを削除 |

- **一括追加**：複数行の文章を貼り付ける（Ctrl+V）か「ボード → カードを一括追加」で、1行につき1枚のカードになります。
- **グループ化**：カードを選んで Ctrl+G を押すと、それらを囲むグループ枠ができ、名前を付けられます。
- **整列**：カードを格子状に並べ直します。「色ごとに並べる」は、同じ色を縦の列にまとめます。
- **ドット投票**：カードに票（赤い点）を付けて、重要なものを見分けられます。
- **矢印**：右クリック →「矢印でつなぐ」で、カードの関係を表せます。
- **画像として書き出す**：ボード全体を PNG 画像にします。
- カードの文字が入りきらないときは、カードが自動で縦に伸びます。

### 書式・表示
- フォントの種類とサイズの変更、文字の拡大・縮小、折り返し、行の縞模様の切り替え

## JSON の形式

```json
{
  "format": "datum-editor",
  "version": 1,
  "mode": "text",
  "fontName": "Monospaced",
  "fontSize": 48,
  "wrap": false,
  "text": "本文"
}
```

`mode` は `text`（横書き）・`vertical`（縦書き）・`board`（カードボード）のいずれかです（以前の版が書いた `kj` も、カードボードとして読めます）。
カードボードでは `text` の代わりに、`cards`（位置・大きさ・色・票数・文字）と `links`（矢印）を保存します。

## 制限

- タイトルバー（ウィンドウ最上部）の色は OS が描くため、アプリからは変えられません。
- 横書きの画面と、横書きの PDF では、ルビは記法のまま（`｜漢字《かんじ》`）表示されます。ルビとして表示されるのは、縦書きの画面と縦書きの PDF です。
- 縦書きの禁則処理は「ぶら下げ」だけです（行末に開きかっこが残る場合の調整などはありません）。
- 検索・置換は、カードボードでは使えません。
- 複数人での同時編集や、クラウドへの保存はありません（ファイルは手元に保存します）。
- PDF は、1ページを1枚の画像として入れています（日本語フォントを PDF に埋め込む処理を避けるため）。見た目はどの PC でも同じですが、PDF の中の文字を選択・検索することはできません。
- Linux と Windows で動作を確認しています。macOS では、まだ実際に動かして確かめていません。

# DATUM-Editor（MiniEditor）

Java（Swing）で作ったテキストエディタです。外部ライブラリは使っていません。
Claude などの AI とつないで、誤字・脱字のチェックや検索、ファイルの整理を頼むこともできます（MCP 対応）。
横書き・縦書き・カードボードの3種類の文書を、タブと画面分割で並べて扱えます。

## ビルド方法

JDK 17 以上と Maven が必要です。

```
mvn package
```

成功すると `target/minieditor.jar` ができます。

## 実行方法

```
java -jar target/minieditor.jar
```

### Windows で動かす

Java で書いてあるので、同じ `minieditor.jar` が Windows・macOS・Linux のどれでも動きます。

1. JDK 17 以上を入れる（例：https://adoptium.net/ ）
2. `minieditor.jar` と `DATUM-Editor.bat` を同じフォルダに置く
3. `DATUM-Editor.bat` をダブルクリックする（または `java -jar minieditor.jar`）

`.jar` は、どの OS で作っても同じものが使えます。Windows 側で `mvn package` をやり直す必要はありません。

### Linux のデスクトップから起動する

`~/Desktop/DATUM-Editor.desktop` のようなランチャーを置き、`Exec=` に `java -jar <minieditor.jar の場所>` を書きます。

### 配布用のファイルを作る

先に `mvn package` をしてから、次のスクリプトを実行すると、`dist/` に配布用のファイルができます。どれも Linux の上で作れます。

| 作るもの | スクリプト | 使う人の側 |
|---|---|---|
| Windows 用 ZIP（Java 同梱） | `sh packaging/build-windows-zip.sh` | 展開して `DATUM-Editor.bat` をダブルクリック。`Create-Desktop-Shortcut.bat` でデスクトップにアイコン |
| Linux 用 `.deb`（Java 同梱） | `sh packaging/build-linux-deb.sh` | `sudo apt install ./ファイル名.deb`。アプリのメニューに登録される |
| Linux 用 `.tar.gz`（Java 同梱） | `sh packaging/build-linux-portable.sh` | 展開して `./bin/DATUM-Editor`。`sh Add-To-Menu.sh` でメニューとデスクトップにアイコン |
| どの OS でも使える ZIP（Java は別に必要） | `sh packaging/build-universal-zip.sh` | `START-HERE.txt` のとおり |

- Windows 用 ZIP は、Windows 向けの Java 実行環境（Eclipse Temurin の JRE）をダウンロードして同梱します。ダウンロードしたファイルは、公開されている検証値（SHA-256）と照らしてから使います。
- Linux 用は、JDK に入っている `jpackage` で、ビルドに使った JDK の実行環境を同梱します。
- 同梱する Java 実行環境は OpenJDK で、GPLv2（クラスパス例外付き）です。利用条件のファイルは、配布物の中の `runtime`（または `lib/runtime`）フォルダに入っています。DATUM-Editor 自体のコードは MIT ライセンスのままです。

## 機能一覧

### 文書の種類

| 種類 | 内容 | 保存形式 |
|---|---|---|
| テキスト | 横書き。行番号、カーソル行の強調、折り返し | `.txt` / `.json` |
| 縦書き | 原稿用紙（20字×20行）に書く。ルビ・傍点・ぶら下げ・縦中横に対応 | `.txt`（なろう形式） / `.json` |
| カードボード | カード（付箋）、グループ枠、カード同士をつなぐ線 | `.json` |

- 「書式 → 横書き ⇔ 縦書き を切り替え」で、同じ文章を横書き・縦書きのどちらでも表示できます。

### 縦書き：原稿用紙とルビ（「小説家になろう」形式）

縦書きの文書は、**原稿用紙（20字×20行、400字詰め）** の形で表示されます。

- 1行は 20 マスで、20 行ごとに1枚の紙として区切り、右から左へ並べます（中央は少し空けてあります）。
- マスの大きさは、20 マスがちょうど収まるように、ウィンドウの高さに合わせて決まります。
- 各行の右にある細い欄が **ルビ欄** です。ルビ欄をクリックすると、となりの文字にふりがなを書き込めます。
- ステータスバーに「原稿用紙 2 / 5 枚」のように、今いる枚数と全体の枚数が出ます。
- 「書式 → 原稿用紙（20字×20行）」（Ctrl+Shift+G）で、マス目のないふつうの縦書きに切り替えられます。
- PDF に書き出すと、A4 横向きの原稿用紙（1ページが1枚）になります。

ルビ（ふりがな）は親文字の右に小さく表示されます。記号は画面に出ません。
`.txt` で保存するときに「小説家になろう」の記法に直して書き出すので、保存したファイルはそのまま投稿欄に貼り付けられます。開くときは、記法を読み取ってルビに戻します。

ルビの振り方は3通りあります。

- **ルビ欄をクリック**：文字の右のルビ欄をクリックすると、その文字（文字を選んでいれば、選んだ範囲）のふりがなを入力できます。
- **メニューから**：文字を選んで「書式 → ルビ（ふりがな）を振る」（Ctrl+R）。文字のすぐ横に入力欄が出るので、ふりがなを打って Enter。空にして Enter で外れ、Esc で取り消しです。ルビの付いた文字をダブルクリックするか、その上で Ctrl+R を押すと、書き直せます。
- **打ち込みで**：`｜山田《やまだ》` のように記法をそのまま打つと、`》` を打った時点でルビに変わります。

| 打ち込む形（＝保存される形） | 意味 |
|---|---|
| `｜山田太郎《やまだたろう》` | `｜` から `《` までの文字に、ルビを振る |
| `漢字《かんじ》` | 漢字が続いているときは、`｜` を省略できる |
| `漢字(かんじ)` `漢字（かんじ）` | かっこでもよい（中が、ひらがな・カタカナだけのとき） |
| `｜《そのまま》` | `｜` の直後がかっこなら、ルビにしない |
| `｜重《・》｜要《・》` | 傍点（1文字ずつ「・」を振る） |

親文字もルビも 10 文字までです（「小説家になろう」の決まり）。保存するときは、すべて `｜親文字《ルビ》` の形にそろえます。

- **傍点**：文字を選んで「書式 → 傍点を付ける」（Ctrl+Shift+R）。
- **外す**：「書式 → ルビ・傍点を外す」。
- ルビは文字に付いているので、前に文章を足しても同じ文字に付いたままです。親文字を消すと、ルビも消えます。
- コピーすると記法の形でクリップボードに入り、貼り付けるとルビに戻ります。
- 横書きの画面は文字だけを扱うので、記法をそのまま表示します。「横書き ⇔ 縦書き」で切り替えると、相互に変換されます。

縦書きでは、ほかに次の組み方をしています。

- **ぶら下げ**：行の先頭に「、」「。」や閉じかっこが来るときは、前の行の一番下に置きます。
- **縦中横**：半角の数字2桁（`12`）や `!?` は、横に並べたまま1文字ぶんに収めます。1桁の数字は立てて表示します。

### ファイル
- 新規（テキスト / 縦書き / カードボード）、開く、保存、名前を付けて保存、タブを閉じる、終了
- 読み書きは UTF-8 です。
- `.txt` は本文だけを保存します。`.json` は、種類・フォント・折り返し・カードの位置なども保存します。
- `.txt` は「縦書きで開く」（Ctrl+Shift+O）を使うと、縦書き（原稿用紙）で開きます。縦書きの文書を見ているときは、ふつうの「開く」でも縦書きで開きます。
- すでに開いているファイルを選んだときは、もう1つ開かずに、そのタブを表示します（同じファイルを2か所で編集して、上書きし合うのを防ぐため）。「縦書きで開く」で選んだ場合は、そのタブをその場で縦書きに切り替えます。未保存の変更は、そのまま残ります。
- 開くときは、JSON の中身を見て種類を自動で判定します。このアプリの形式ではない `.json` は、中身をそのままテキストとして開きます（保存しても形式は変わりません）。
- 未保存の変更があるタブを閉じる・終了するときは、確認ダイアログを出します。
- **PDF として書き出す**（Ctrl+Shift+P）：テキストと縦書きは A4 の紙に割り付け（白地に黒文字、ページ番号付き）、カードボードは全体を1ページにします。
- 「開く」「保存」の画面は、最後に保存したフォルダから始まります（エディタを閉じても覚えています）。まだ保存したことがなければ、デスクトップから始まります。
- 未保存のタブには `●` が付きます。読み書きに失敗したときは、ダイアログで知らせます。

### AI 連携（MCP）

エディタを「MCP サーバー」にして、Claude などの AI から、開いている文書やファイルを扱えるようにする機能です。
MCP（Model Context Protocol）は、AI が外のソフトの機能を「道具」として使うための共通の決まりです。

**AI に頼めること**

- **誤字・脱字のチェック**：開いている文書を読んで、直す所を示し、書き換えます。書き換えた所は緑色になり、Ctrl+Z の1回でまとめて元に戻せます。
- **検索**：今の文書、開いている文書すべて、フォルダの中のファイルから、言葉を探します（正規表現も使えます）。
- **ファイルの扱い**：ファイルを開く・読む、新しい文書を作る、保存する、名前を変える・移動する、フォルダを作る、ごみ箱へ入れる。

**始め方**

1. メニューの「AI 連携 → MCP サーバーを動かす」にチェックを入れます。
2. 最初に「AI に任せるフォルダ」を選びます。AI が読み書きできるのは、このフォルダの中と、エディタで開いている文書だけです。原稿を入れた専用のフォルダを選んでください。
3. 「接続のしかた」の画面が出ます。お使いの AI に合わせて、表示された内容をコピーして登録します。
   - **Claude Code**：表示されたコマンド（`claude mcp add datum-editor -- …`）を、ターミナルで1回実行します。
   - **Claude Desktop**：表示された設定を、`claude_desktop_config.json` に書き足して、Claude Desktop を再起動します。
   - **そのほか**：`http://127.0.0.1:8765/mcp` に、表示された合言葉（`Authorization: Bearer …`）を付けてつなぎます。
4. あとは AI に、「今開いている文書の誤字脱字を直して」「『猫』が出てくる所を全部探して」「この文書を 第一章.txt で保存して」のように頼みます。

一度チェックを入れると、次にエディタを起動したときも、自動で動きます。動いている間は、ステータスバーに「AI 連携中」と出ます。

**安全のためのしくみ**

- つながるのは、この PC の中からだけです（127.0.0.1 で待ち受けます）。インターネット側からは届きません。
- 合言葉（起動ごとではなく、利用者ごとに1つ。自動で作られます）を知っているプログラムだけが使えます。
- ブラウザで開いたページから勝手に使われないように、ブラウザからの通信は断ります。
- フォルダの外は、`../` やリンクを使っても扱えません。
- AI が保存で別のファイルを上書きするとき、未保存の文書を閉じるときは、AI にその旨の指定（利用者に確かめたうえで付けるもの）を求めます。
- 「ごみ箱へ」は、フォルダの中の `.datum-trash` に移すだけです。完全には消しません。

**知っておいてほしいこと**

- AI に文書を読ませると、その内容は、お使いの AI のサービスに送られます。外に出したくない原稿では、使わないでください。
- AI のアプリは、エディタとは別の「橋渡し役」（同じ JAR を `--mcp-stdio` 付きで起動したもの）を通してつながります。エディタが起動していない、または AI 連携が止まっているときは、AI に「エディタを起動してください」と伝わります。
- AI 連携を使えるのは、同時に1つのウィンドウだけです。
- カードボードは、AI からは読むことと、新しく作ることだけができます（カードの書き換えはできません）。

### タブと画面分割
- 複数の文書をタブで開けます（`+` で追加、`×` または中ボタンで閉じる）。
- 「表示 → 画面を分割」で左右（または上下）に2つ並べ、それぞれ別の文書・別の種類を表示できます。
- タブを反対側へ移動できます。

### 編集
- 元に戻す / やり直し、切り取り / コピー / 貼り付け、すべて選択

### 検索・置換（テキスト・縦書き）
- 入力するたびに、一致箇所をすべて水色で表示します（今いる場所は明るい水色）。
- Enter で次へ、Shift+Enter で前へ。最後まで行くと先頭に戻ります。件数と、何件目かを表示します。
- `Aa` ボタンで、大文字と小文字を区別するかを切り替えます。
- 置換した場所は緑で表示します。「すべて置換」は、「元に戻す」1回で戻せます。

### カードボードの操作

Miro・FigJam・Mural などのオンラインのボードにある機能を参考にしています。

| 操作 | 内容 |
|---|---|
| 何もない所をダブルクリック | カードを追加 |
| カードをダブルクリック / Enter | 文字を編集（Ctrl+Enter か外をクリックで確定、Esc で取り消し） |
| ドラッグ | 移動（グループ枠を動かすと、中のカードも一緒に動く） |
| 何もない所からドラッグ | 囲んだカードをまとめて選択（Shift+クリックで追加・解除） |
| ふちや角をドラッグ | 大きさを変える（ふちに触れると矢印の形が変わる。カードもグループ枠も同じ） |
| Ctrl+ホイール / 中ボタンでドラッグ | 拡大・縮小 / 表示位置を動かす |
| 右クリック | 色、投票、矢印、整列、グループ化、複製、削除 |
| Delete | 選んでいるカードを削除 |

- **一括追加**：複数行の文章を貼り付ける（Ctrl+V）か「ボード → カードを一括追加」で、1行につき1枚のカードになります。
- **グループ化**：カードを選んで Ctrl+G を押すと、それらを囲むグループ枠ができ、名前を付けられます。
- **整列**：カードを格子状に並べ直します。「色ごとに並べる」は、同じ色を縦の列にまとめます。
- **ドット投票**：カードに票（赤い点）を付けて、重要なものを見分けられます。
- **矢印**：右クリック →「矢印でつなぐ」で、カードの関係を表せます。
- **画像として書き出す**：ボード全体を PNG 画像にします。
- カードの文字が入りきらないときは、カードが自動で縦に伸びます。

### 書式・表示
- フォントの種類とサイズの変更、文字の拡大・縮小、折り返し、行の縞模様の切り替え
- VS Code に近い暗い配色、ステータスバー（行・列・文字数・文字コード・保存形式）

### 原稿を失わないためのしくみ
- **自動バックアップ（異常終了からの復旧）**：未保存の変更がある文書は、30 秒ごとに裏で控えを取ります。エディタが異常終了しても、次に起動したときに「復元する／捨てる／あとで決める」を選べます。ふつうに終了したときは、控えを消します。
- **自動保存（設定で選んだときだけ）**：保存先のある文書を、30 秒ごとに上書き保存します。
- **版の履歴**（ファイル → 版の履歴…、Ctrl+Shift+H）：保存するたびに、その版を残します（既定は 1 ファイル 50 個まで）。版を選ぶと内容と「今との違い」（増えた行・減った行）を表示し、「この版に戻す」「別のタブで開く」ができます。戻すときは今の内容も履歴に残すので、戻したあとでも元に戻れます。AI が保存したときも残ります。
- **前回の状態を復元**：終了したときに開いていたタブ（縦書きかどうかも）、カーソルの位置、画面分割、ウィンドウの位置と大きさ、サイドバーと右の欄を覚えておき、次の起動で元に戻します。

控えや履歴は、設定フォルダ（Linux は `~/.config/datum-editor/`、Windows は `%APPDATA%\datum-editor\`）の `recovery` と `history` に入ります。

### フォルダのサイドバー
- メニューバー右端の「フォルダ」（Ctrl+Shift+E）で、左にフォルダの中身を表示します。「開く…」で原稿のフォルダを選び、クリックでファイルを開きます。
- 並びは名前の順で、数字は数として比べます（「第2章」は「第10章」より前）。
- 右クリック：新しいテキストファイル、新しいフォルダ、名前を変える、ごみ箱へ移す（フォルダの中の `.datum-trash` へ移すだけです）、**このフォルダの文章を1つにまとめる**（名前の順につないで、新しいタブに開きます）。

### 校正チェック（AI を使わない）
- 「校正」（F7）で、右に気になる所の一覧を出します。文書を書き換えると、少し待ってから自動で調べ直します。文章は外に送りません。
- 調べる項目：ら抜き言葉、二重敬語、重複表現（頭痛が痛い など）、記号の使い方（「……」「――」、！？のあとの空白、閉じかっこ前の「。」）、表記ゆれ（全て／すべて、全角／半角の英数字 など）、段落の字下げ、かっこの対応、長い文、文末の繰り返し、「の」の連続、半角カタカナ。
- 一覧をクリックすると、その場所を選びます。案があるものは「直す」で書き換えます（Ctrl+Z で戻せます）。「無視」で、その言葉を今回は一覧から外します。「項目」で、使わない項目を外せます。
- 規則で探すだけなので、間違いとは限りません（会話文でわざと崩している場合など）。

### 執筆の記録
- ステータスバーに、今日書いた字数（「今日 +1,234 字」）と、テキストの文書では 400 字詰め原稿用紙に換算した枚数を出します。
- ステータスバーの右端に、今日の字数と目標の進み具合を「今日 1,234 / 3,000 字 ■■■■□□□□□□ 41%」のように出します（1 マス＝10%、目標に届くとマスが緑になります）。ここをクリックすると、目標字数をその場で入力できます（1,000・2,000・3,000・5,000 字と「目標なし」はボタン1つで選べます）。
- 「表示 → 執筆の記録…」で、直近 14 日の棒グラフ、7 日・30 日の合計、連続日数を表示します。
- 数えるのは、その日に増えた字数です（開いた時点の字数は数えず、消すと減ります）。

### 集中モード
- 「集中」（F11）で、メニュー・タブ・ステータスバー・左右の欄を隠し、ウィンドウを最大にします。テキストの文書では、1 行 40 字ほどの幅で中央に寄せ、カーソルの行をいつも画面の真ん中に保ちます。F11 か Esc で元に戻ります。
- 隠れていても、Ctrl+S などのショートカットはそのまま使えます。

### AI の会話欄
- 「AI」（Ctrl+Shift+A）で、右に会話欄を出します。頼みごとを書いて Enter で送ります（改行は Shift+Enter）。「誤字・脱字」「表記ゆれ」「要約」はボタン1つで頼めます。
- AI は、AI 連携（MCP）と同じ道具（文書を読む・直す・探す・保存する、フォルダの中のファイルを扱う）を使います。AI が直した所は Ctrl+Z で戻せます。
- 使う AI は「ファイル → 設定…」で選びます。

| 使う AI | 内容 | 料金 |
|---|---|---|
| Claude Code | この PC に入っている Claude Code（`claude` コマンド）を裏で動かします。先にターミナルで一度 `claude` を起動してログインしておいてください。使うときは AI 連携（MCP）を自動で動かします | Claude の月額プランでログインしていれば、その利用枠から |
| Anthropic API | API キーで Claude を直接使います（モデルを空にすると claude-opus-5-5） | 使った分だけ（従量課金） |
| OpenAI 互換 API | ChatGPT・Gemini・OpenRouter・Ollama など、同じ形の窓口を持つ AI。接続先 URL とモデル名を入れます（Ollama なら `http://localhost:11434/v1`、API キーは空でよい） | サービスによる（Ollama は PC の中で動くので無料） |

- 送った文章や、AI が読んだ文書は、選んだ AI のサービスに送られます（Ollama などの PC の中で動く AI を除く）。
- API キーは設定フォルダの `settings.json`（本人だけが読める権限）に保存します。暗号化はしていません。
- Claude Code を使う形は、利用者自身がログインした Claude Code をそのまま呼び出すだけで、このエディタがログイン情報を扱うことはありません。利用の条件は、Anthropic の [Legal and compliance](https://code.claude.com/docs/en/legal-and-compliance) を確かめてください。

### 設定と配色
- 「ファイル → 設定…」（Ctrl+,）で、配色（ダーク／ライト）、自動保存、版の履歴の数、1日の目標、AI の設定をまとめて変えられます。配色は、次に起動したときに変わります。

### ターミナル
- メニューバーの右端には「フォルダ」「校正」「AI」「>_」「集中」のボタンが並び、1回押すだけで欄を出し入れできます（出ている間は青くなります）。
- `>_` ボタン（または Ctrl+J）で、エディタの下にターミナルを出し入れできます。隠しても、中で動いているコマンドは止まりません。
- 下の入力欄にコマンドを書いて Enter で実行します。↑↓ で前に入力した行を呼び出せます。「中断」（Ctrl+C）で、動いているコマンドを止めます。
- 始まる場所は、今の文書を保存してあるフォルダです（未保存なら、「開く」の画面と同じ場所）。
- 1行ずつ送る方式の、かんたんなターミナルです。`ls`、`git`、`mvn` のように文字を順に出すコマンド向けで、画面全体を書き換えるプログラム（`vim`、`top`、対話式の AI の画面など）は表示できません。

## JSON の形式

```json
{
  "format": "datum-editor",
  "version": 1,
  "mode": "text",
  "fontName": "Monospaced",
  "fontSize": 48,
  "wrap": false,
  "text": "本文"
}
```

`mode` は `text`（横書き）・`vertical`（縦書き）・`board`（カードボード）のいずれかです（以前の版が書いた `kj` も、カードボードとして読めます）。
カードボードでは `text` の代わりに、`cards`（位置・大きさ・色・票数・文字）と `links`（矢印）を保存します。

## 制限

- AI 連携の HTTP サーバーには、JDK に入っている `com.sun.net.httpserver`（`jdk.httpserver` モジュール）を使っています。外部のライブラリではありませんが、`java.` や `javax.` で始まる標準 API ではなく、JDK に付属する API です。

- タイトルバー（ウィンドウ最上部）の色は OS が描くため、アプリからは変えられません。
- 横書きの画面と、横書きの PDF では、ルビは記法のまま（`｜漢字《かんじ》`）表示されます。ルビとして表示されるのは、縦書きの画面と縦書きの PDF です。
- 縦書きの禁則処理は「ぶら下げ」だけです（行末に開きかっこが残る場合の調整などはありません）。
- 検索・置換は、カードボードでは使えません。
- 複数人での同時編集や、クラウドへの保存はありません（ファイルは手元に保存します）。
- PDF は、1ページを1枚の画像として入れています（日本語フォントを PDF に埋め込む処理を避けるため）。見た目はどの PC でも同じですが、PDF の中の文字を選択・検索することはできません。
- ターミナルは、Linux でだけ動作を確認しています（Windows と macOS では、まだ確かめていません）。
- AI の会話欄の「Anthropic API」「OpenAI 互換 API」は、偽のサーバーを使ったテストでだけ確かめています（実際のサービスにはつないでいません）。「Claude Code」は Linux で実際に動かして確かめました。
- AI の会話欄の通信には、Java 標準の `java.net.http` を使っています（外部のライブラリは使っていません）。
- Linux と Windows で動作を確認しています。macOS では、まだ実際に動かして確かめていません。

DATUM-Editor（Windows 用）の使い方
==================================

Java を入れる必要はありません（このフォルダの「runtime」に入っています）。

■ 起動する
「DATUM-Editor.bat」をダブルクリックします。
・「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を選びます。
・必ず、ZIP をすべて展開してから実行してください（ZIP の中から直接は起動できません）。

■ デスクトップにアイコンを作る
「Create-Desktop-Shortcut.bat」をダブルクリックします。
デスクトップに「DATUM-Editor」のアイコンができ、次からはそれをダブルクリックするだけで起動できます。
・このフォルダを別の場所に移したときは、もう一度実行してください。
・置き場所は、ドキュメントの中など、消さない場所がおすすめです。

■ ファイルを指定して開く
.txt などのファイルを「DATUM-Editor.bat」かデスクトップのアイコンの上に引きずって落とすと、そのファイルを開きます。
すでに開いているときは、そのウィンドウのタブで開きます。
コマンドプロンプトから「DATUM-Editor.bat 原稿.txt」と打っても開けます。

■ 「datum」と打つだけで起動する
初めて起動したときに「datum で起動できるようにしますか？」と聞かれるので、「はい」を選びます。
そのあと、新しく開いたコマンドプロンプトや PowerShell で「datum」と打つと起動し、「datum 原稿.txt」と打つとそのファイルを開きます。
・このフォルダを別の場所に移したときは、次の起動で自動的に登録し直します（前の場所の登録は残るので、気になるときは移す前に Remove-Command.bat を実行してください）。
・「いいえ」を選んだあとでも、「設定」のチェックか「Add-Command.bat」で、あとから登録できます。
・やめるときは「Remove-Command.bat」をダブルクリックします（自分のユーザーの PATH から、このフォルダを外します）。

■ 消すとき
このフォルダと、デスクトップのアイコンを削除するだけです（レジストリなどは使っていません）。

■ AI（Claude など）とつなぐ
誤字・脱字のチェックや検索、ファイルの整理を、AI に頼めます。
メニューの「AI 連携 → MCP サーバーを動かす」にチェックを入れると、つなぎ方の案内が出ます。
